Download Harbor for Mac

The free app for playing Windows games on Apple silicon. Version 0.7.0, early access.

Requirements

  • A Mac with Apple silicon: M1 or later. Intel Macs are not supported.
  • macOS 14.6 or later.
  • Rosetta, which Harbor's Wine runs through. Harbor tells you if it is missing (how to install it).
  • About 3 GB of free space to set up, plus room for your games, and an internet connection.

Install Harbor

  1. Download Harbor-0.7.0.zip from the latest release on GitHub.
  2. Open the zip and move Harbor to your Applications folder.
  3. Open Harbor. The first time, macOS stops it; see the next section.
  4. Choose Prepare Harbor. Harbor downloads Wine and the renderers once (a few hundred MB), checks each against its SHA-256 checksum, and sets them up in ~/Library/Application Support/Harbor.
  5. Choose Bottles › New Bottle…, pick Steam, the EA app, Ubisoft Connect or an empty bottle, and follow the guide for your launcher.

“Harbor” can't be opened: allowing it the first time

Harbor is not notarized by Apple yet, so the first time you open it, macOS says it can't check the app and doesn't open it. You allow it once:

  1. Try to open Harbor, then close the message.
  2. Open System Settings › Privacy & Security and scroll down to Security.
  3. Next to the message about Harbor, choose Open Anyway, then confirm with your password or Touch ID.

From then on Harbor opens like any other app.

Installing Rosetta

Rosetta lets Apple silicon Macs run apps made for Intel processors. The Windows compatibility layer Harbor uses (Wine) runs through it, while Harbor itself runs natively. If Rosetta is missing, Harbor says so before setting up. To install it, open Terminal and run:

softwareupdate --install-rosetta

Accept Apple's licence when Terminal asks, then choose Prepare Harbor again.

Check your download

To make sure the file you downloaded is the one published, open Terminal in the folder with the zip and run shasum -a 256 Harbor-0.7.0.zip. The result must be:

bcb76a69bde68e041b3b3b583e9b0936284622a4e5187b8e0c6dcf73fe7dbf4a

What Harbor downloads, and from whom

Harbor itself contains only its own code. When you ask it to, it downloads:

WhatFromLicence
Wine 11, DXMT and MoltenVKHighball's public releases on GitHub (Wine built from the sources CodeWeavers publishes)LGPL, Apache-2.0
D3DMetal, DXVK, GStreamer, SDL and support librariesThe Sikarugir project's public template on GitHubApple's Game Porting Toolkit licence for D3DMetal; open-source licences for the rest
Steam, the EA app, Ubisoft ConnectValve, Electronic Arts and UbisoftTheir own terms, shown by their installers
Visual C++, .NET and DirectX componentsMicrosoftMicrosoft's terms; Harbor asks you to accept them first

D3DMetal is Apple's, from the Game Porting Toolkit, licensed for non-commercial use in developing, testing and evaluating games on Apple hardware. Harbor is free and non-commercial and installs it unmodified.

Uninstall Harbor

  1. Quit Harbor and move it from Applications to the Trash.
  2. To remove your bottles too, including installed games and their saves, move ~/Library/Application Support/Harbor to the Trash. In Finder, choose Go › Go to Folder… and paste that path.
  3. If you made save backups, they are in ~/Documents/Harbor Backups.
