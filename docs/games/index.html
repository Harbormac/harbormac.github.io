Windows games that run on a Mac

459 Windows games that players report running well on Macs with Apple silicon through Wine, the technology Portnaut uses. Each has a report rated 4 or 5 out of 5 after at least ten minutes of play, or was played by the database's maintainer.

From Highball's open compatibility database · 20 played by its maintainer · Not tested with Portnaut unless a guide says so · Updated 10 November 2026

How to read this list

  • It shows what runs, not what doesn't. Games that don't start, and games blocked by kernel-level anti-cheat, are left out. A game that isn't here may still run: nobody has reported it yet.
  • These are players' reports, not Portnaut's tests. They come from Highball's open compatibility database, where Mac players report how a game ran. Portnaut has its own guides for the games it covers in depth; those are linked.
  • Wine 11 matters. Most reports were made with Highball's Wine 10. Portnaut installs Highball's Wine 11 build, and 81 games here have a good report on that Wine too. For the others, treat the report as a strong hint, not a promise.
  • Check for a Mac version first. If a game has one, it'll run better than any Windows version.

Portnaut's Will It Run? (⌘K in the app) checks about 13,000 games, including anti-cheat and what Linux players' results predict. Download Portnaut, free.

What the columns mean

  • Result: how many players rated the game 4 (playable, minor issues) or 5 (perfect) after ten minutes or more, and the best rating. “Played by Highball” means the database's maintainer played it.
  • Renderer: the graphics renderer most good reports used. In easy mode, Portnaut picks this one when you press Play. How the renderers differ.
  • Wine 11 report: whether a good report used the Wine 11 build that Portnaut installs.
  • Played on: the chips of the Macs in those reports. A18 Pro is the MacBook Neo.

Questions

What games can I play on a Mac?

Games with a Mac version, and many Windows games through Wine. This list has 459 Windows games that players report running well on Apple silicon. Games with kernel-level anti-cheat don't run, and some games run only offline.

Do all of these run in Portnaut?

They've been reported running on Macs through Wine with Highball, not tested with Portnaut. Portnaut installs Highball's Wine 11 build and the same renderers, so most should behave alike, but only the games with a Portnaut guide have been checked more closely.

My game isn't on the list. Does that mean it won't run?

No. It means nobody has reported it yet. Search it in Portnaut's Will It Run?, which also uses Linux players' results to predict how likely a game is to run, and names anti-cheat that blocks it.

Where does the list come from?

From Highball's compatibility database, which is open and free to reuse (CC0). Players send reports from the Highball app with their Mac's chip, macOS version and a rating. Portnaut rebuilds this page from it.
