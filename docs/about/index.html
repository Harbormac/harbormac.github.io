About Portnaut

Portnaut is a free Mac app for playing Windows games on Apple silicon. It is made by Built by Argo and is open source under the MIT licence.

Why Portnaut exists

Many games, and the launchers that sell them, only come for Windows. Running them on a Mac usually means setting up Wine by hand. Portnaut does that setup for you: it keeps each launcher in its own bottle, recommends a renderer for each game, and lets you snapshot a bottle before you change anything.

Free and open source

Portnaut costs nothing and has no accounts, ads or tracking. Its source code is on GitHub, so anyone can check what it does, report a problem or suggest a change. If Portnaut is useful to you, you can support it on Ko-fi.

How things are tested, and what the labels mean

A page about running games is only useful if you can tell what was really tried. Every guide here says so under its title, in one of three ways:

  • Tested with Portnaut: we did it ourselves, on our own Mac (a MacBook Pro with an M4 Pro), and the page names the Portnaut version or the month. So far that covers Assassin's Creed III Remastered through Ubisoft Connect, and each launcher up to its sign-in page.
  • Played on a Mac, as recorded in Highball's database: the maintainer of Highball's open compatibility database played it, with the Wine build Portnaut also installs or one close to it. We haven't played it through Portnaut.
  • Players report: Mac players sent a report with their chip, macOS version and a rating. Nobody has verified it. The games list is made from these.

What you won't find here:

  • Games that don't run. There's no guide for a game that doesn't work on a Mac, and where a game runs only offline, the guide says so first.
  • Paid placement, affiliate links or ads. The only money link is the optional Ko-fi donation, which unlocks nothing.
  • Guesses presented as results. Frame rates are quoted with the Mac they were measured on and who measured them.

Found something wrong or out of date? Write to builtbyargo@proton.me and it gets corrected.

What Portnaut builds on

Portnaut is the app around a set of open-source projects, each under its own licence:

  • Wine runs Windows programs on macOS.
  • DXMT, Apple's D3DMetal and DXVK with MoltenVK translate DirectX graphics to Metal.
  • GStreamer plays in-game video, and SDL handles controllers.

Portnaut downloads these when you prepare it. The download page lists where each one comes from and its licence.

Who makes Portnaut

Portnaut is made by Built by Argo, an independent developer. It started as a way to play Assassin's Creed III Remastered on a Mac without setting Wine up by hand. The app is written in Swift, and every release is published with its source code and a checksum. It is not affiliated with Apple, Valve, Electronic Arts, Ubisoft, Epic Games, Blizzard Entertainment, Rockstar Games, GOG, Amazon, Microsoft or Highball.
