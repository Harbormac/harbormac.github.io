About Harbor

Harbor is a free Mac app for playing Windows games on Apple silicon. It is made by Built by Argo and is open source under the MIT licence.

Why Harbor exists

Many games, and the launchers that sell them, only come for Windows. Running them on a Mac usually means setting up Wine by hand. Harbor does that setup for you: it keeps each launcher in its own bottle, recommends a renderer for each game, and lets you snapshot a bottle before you change anything.

Free and open source

Harbor costs nothing and has no accounts, ads or tracking. Its source code is on GitHub, so anyone can check what it does, report a problem or suggest a change. If Harbor is useful to you, you can support it on Ko-fi.

What Harbor builds on

Harbor is the app around a set of open-source projects, each under its own licence:

  • Wine runs Windows programs on macOS.
  • DXMT, Apple's D3DMetal and DXVK with MoltenVK translate DirectX graphics to Metal.
  • GStreamer plays in-game video, and SDL handles controllers.

Harbor downloads these when you prepare it. The download page lists where each one comes from and its licence.

Who makes Harbor

Harbor is made by Built by Argo, an independent developer. It is not affiliated with Apple, Valve, Electronic Arts, Ubisoft or Microsoft. Questions, bug reports and ideas go to builtbyargo@proton.me.
