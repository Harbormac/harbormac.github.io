What's new in Portnaut

The changes in each version of Portnaut, newest first. Every release is also on GitHub, with its download and checksum.

Latest version: Portnaut 0.12.0 · 1 November 2026

Portnaut 0.12.0 · 1 November 2026

Install a game and play: easy mode, Will It Run?, five more launchers and Couch Mode.

  • Five more launchers: the Epic Games Launcher, Battle.net, the Rockstar Games Launcher, GOG Galaxy and Amazon Games, each installed from its publisher's own installer. Games from Epic, GOG and Amazon Games appear by themselves; Epic games start through the launcher, so they're signed in.
  • Easy mode, on for new bottles: when you press Play, Portnaut switches the bottle to the renderer that suits the game and backs up your saves first. Bottles from earlier versions keep working as they did until you turn it on.
  • Will It Run? (Command-K): check about 13,000 games before you buy or download one, from Highball's open compatibility database. Games in your library show their verdict, and Portnaut warns you when Steam starts downloading a game that can't run.
  • Find My Best Setup: Portnaut plays a game once on each renderer it can use, measures every round on your Mac, and keeps the fastest.
  • Couch Mode (Shift-Command-T): your library full screen for a TV, driven by a controller.
  • Automatic save backups before every game, ten kept.
  • Launcher windows that draw: Battle.net, Rockstar's Social Club, GOG Galaxy and Amazon Games showed blank windows under Wine on a Mac. Portnaut sets each one up to draw in software. Rockstar bottles use DXMT, because the Rockstar Games Launcher doesn't start on D3DMetal.
  • GTA V and Red Dead Redemption 2 from Steam: Rockstar's sign-in window now draws in every bottle, because these games open the Rockstar Games Launcher from Steam too. GTA V Legacy gets the launch option -nobattleye by itself, so its story mode starts; GTA Online needs BattlEye, which Wine can't run. GTA 5 on a Mac · Red Dead Redemption 2 on a Mac.
  • Clearer verdicts: only games played on a Mac show as “Tested on Apple silicon”; a Wine release's notes now count as a report.

Each new launcher is tested up to its sign-in screen. Not yet tried with real games: signing in and playing in the new launchers, Find My Best Setup's rounds, and Couch Mode with a controller. GTA V and Red Dead Redemption 2 haven't been played through Portnaut yet: their setup follows Highball's database, where both were played on a Mac. Reports are welcome at builtbyargo@proton.me. If a launcher won't open.

New for privacy: when you open Component Updates, Portnaut also fetches the newest compatibility list. Will It Run? works on your Mac and never sends what you play. Privacy.

Portnaut 0.8.0 · 30 October 2026

A new name, a new look, and the full source code.

  • Portnaut: a new name and a new icon, the gamepad planet.
  • A new look: deep-space colours with rocket-orange buttons, rounded headings, and starry scenery for games without their own artwork.
  • The full source code is now public on GitHub, under the MIT licence. It builds with Apple's Command Line Tools; Xcode isn't needed.
  • Build scripts now build inside the repository.

Everything else works as before:

  • bottles for Steam, the EA app and Ubisoft Connect;
  • a renderer recommendation for each game;
  • per-game settings and controllers;
  • Windows components from Microsoft;
  • snapshots and save backups;
  • performance records for every session;
  • component updates for Wine and the renderers, with roll back.

Release notes on GitHub

How to update Portnaut

Portnaut doesn't update itself yet. To move to a new version:

  1. Download the new version and open the zip.
  2. Quit Portnaut, then move the new Portnaut to your Applications folder and choose Replace.
  3. Open it. macOS may ask you to allow it again, as the first time.

Your bottles, games and saves stay where they are, in ~/Library/Application Support/Portnaut, so nothing needs setting up again.

Wine and the renderers update separately, from inside the app: choose Check for Component Updates… in the Portnaut menu. How component updates work.

To hear about new versions, open the Portnaut repository on GitHub and choose Watch › Custom › Releases.

Good to know

  • Portnaut is in early access. Keep backups of saves you care about: Back Up Saves in a bottle copies them to ~/Documents/Portnaut Backups.
  • Games with kernel-level anti-cheat don't run under Wine.
  • DirectX 12 games need D3DMetal. About D3DMetal and the Game Porting Toolkit.
