Where to start

New to all this? How to play PC games on a Mac walks through it from the start. New to Portnaut? Install it first and choose Prepare Portnaut, then pick the guide for the store your games are in. Each launcher gets its own bottle: a separate Windows environment, so one launcher's settings and updates never affect another. New bottles start in easy mode, which picks the renderer for each game when you press Play.

Before you buy or download a game, check it with Portnaut's Will It Run? (⌘K). It knows about 13,000 games: the ones played on a Mac, the ones Mac players report working, and the ones blocked by anti-cheat. Some games run only their single-player part: GTA 5's story mode plays, GTA Online doesn't. Games with kernel-level anti-cheat don't run at all, and Will It Run? says so.

You don't need to know how any of it works. If you're curious, DXMT vs D3DMetal vs DXVK explains the renderers, and if something doesn't work, troubleshooting lists the fixes for the common problems.
