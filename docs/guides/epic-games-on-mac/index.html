How to play Epic Games Store games on a Mac

The Mac version of the Epic Games Launcher only installs games made for macOS. With Portnaut you can run the Windows version on a Mac or MacBook with Apple silicon and install the Windows games in your Epic library, including the free ones.

Launcher tested with Portnaut 0.12.0 on macOS 27.2 · Updated 2 November 2026

What has been tested

The Windows Epic Games Launcher installs and opens to its sign-in page in Portnaut, with nothing to set up by hand. How well a particular game then runs depends on the game: Portnaut's Will It Run? (⌘K) checks about 13,000 games before you download one.

Install the Epic Games Launcher in Portnaut

  1. Download Portnaut, open it, and choose Prepare Portnaut.
  2. Create an Epic Games bottle. Choose Bottles › New Bottle…, select Epic Games and keep easy mode on.
  3. Install the launcher. Choose Install Epic Games Launcher. Portnaut downloads Epic's own installer and installs it with a progress bar.
  4. Sign in. Choose Open Epic Games Launcher and sign in. Your password goes to Epic; Portnaut never sees or stores it.
  5. Install a game as you would on a PC. When Epic finishes installing it, it appears in Portnaut's library by itself.
  6. Play from Portnaut's library. Epic games start through the launcher, which signs them in to Epic's online services; in easy mode, Portnaut first switches the bottle to the renderer that suits the game.

Good to know

  • Check a game first. Games protected by anti-cheat that runs in the Windows kernel can't run under Wine, in Portnaut or anywhere else. Will It Run? names them.
  • Online and anti-cheat: some games run but block online play under Wine. Will It Run? says when a game's anti-cheat may do that.
  • Free games: games you claim on Epic's Mac app or website are in the same library, so the Windows launcher in Portnaut shows them too.

Questions

Can I play Epic Games Store games on a Mac?

Games with a Mac version, through Epic's Mac app. Windows-only games, through the Windows Epic Games Launcher in Portnaut, if the game itself runs under Wine. Check it with Will It Run? first.

Do I need a second Epic account?

No. Sign in with the account you already have; your library is the same on every platform.

Is it free?

Portnaut and the Epic Games Launcher are free. Games cost what they cost on Epic.
