Battle.net on an Apple silicon Mac: what works

Battle.net works on Macs and MacBooks with Apple silicon. Blizzard's own Mac app covers the Blizzard games made for macOS, such as World of Warcraft, Hearthstone and StarCraft II: use it for those. For Blizzard's Windows-only games, Portnaut runs the Windows Battle.net app.

Battle.net app tested up to its sign-in page (macOS 27.2, 1 November 2026); no game played through it yet · Updated 6 November 2026

Is Battle.net native on Apple silicon?

Apparently not yet. A check posted on Blizzard's forums in September 2026 found the Battle.net Mac app still built only for Intel, which means it runs through Rosetta. That's one player's check; we found no announcement from Blizzard either way. World of Warcraft itself has run natively on Apple silicon since 2020.

What has been tested with Portnaut

  • The Windows Battle.net app installs and opens to its sign-in page in Portnaut. Its window would stay white on a Mac; Portnaut sets it up to draw.
  • Overwatch 2: a player reports it playing well on a Mac with Apple silicon, recorded in Highball's open compatibility database. It hasn't been verified there or by us yet.
  • Other Blizzard games: check each one with Portnaut's Will It Run? (⌘K) before installing it. Some Blizzard games use anti-cheat that Wine can't run.

Install the Windows Battle.net app in Portnaut

  1. Download Portnaut, open it, and choose Prepare Portnaut.
  2. Create a Battle.net bottle. Choose Bottles › New Bottle…, select Battle.net and keep easy mode on.
  3. Install Battle.net. Choose Install Battle.net and follow Blizzard's installer.
  4. Sign in with your Battle.net account. Your password goes to Blizzard; Portnaut never sees or stores it.
  5. Install a game from Battle.net. Battle.net gives each game a folder of its own; in Portnaut, choose Programs › Find Programs to add it to the library, or start it from Battle.net.

Questions

Is Battle.net native on Apple silicon?

Apparently not yet. A check posted on Blizzard's forums in September 2026 found the Mac app still built only for Intel, so it runs through Rosetta. World of Warcraft itself is native.

Does Battle.net work on a Mac?

Yes, Blizzard makes a Mac app for its Mac games, such as World of Warcraft, Hearthstone and StarCraft II. Windows-only Blizzard games need the Windows Battle.net app, which Portnaut runs on Macs with Apple silicon.

Can I play Overwatch 2 on a Mac?

A player reports it playing well through Wine on a Mac with Apple silicon; it hasn't been verified yet. It's free, so you can try it in a Battle.net or Steam bottle in Portnaut.

Is it free?

Portnaut and Battle.net are free. Games cost what they cost on Battle.net.
