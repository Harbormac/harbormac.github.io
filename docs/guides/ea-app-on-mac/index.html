How to run the EA app on a Mac

Portnaut installs the Windows EA app on an Apple silicon Mac in its own bottle, so you can play EA games that run under Wine, for free.

EA's installer tested up to its agreement screen (October 2026); the EA app's sign-in and games haven't been tested yet · Updated 10 November 2026

Is there an EA app for Mac?

Yes. EA makes a Mac version of the EA app for its games that have a Mac version, such as The Sims 4. If your game is one of those, use EA's Mac app: it runs better than a Windows version could.

For EA's Windows-only games, the Windows EA app has to run through Wine. Here's what is known, honestly:

  • It can work. The maintainer of Highball's open compatibility database installed and played The Sims 4 through the Windows EA app on an M1 Pro, on Highball's Wine 11, the line Portnaut installs too, with settings Highball applies for the EA app.
  • Portnaut's own setup is the least tested. EA's installer has been run up to its agreement screen; signing in and playing haven't been tested with Portnaut yet.
  • EA's biggest online games don't run on any Mac through Wine, because of their anti-cheat. See below.

Before you start

Download and install Portnaut, open it, and choose Prepare Portnaut.

Install the EA app in Portnaut

  1. Create an EA app bottle. Choose Bottles › New Bottle…, select EA app, keep the recommended renderer, D3DMetal, and choose Create.
  2. Install the EA app. Choose Install EA app. Portnaut downloads EA's own installer; accepting EA's terms in it is your step. When it finishes, it doesn't open the EA app by itself.
  3. Sign in. Choose Open EA app and sign in. Your password goes to EA; Portnaut never sees or stores it.
  4. Install a game in the EA app. Games the EA app records join Portnaut's library by themselves; for anything else, choose Programs › Find Programs in the bottle.
  5. Play from Portnaut's library or from the EA app.

Which renderer to use

An EA app bottle starts on D3DMetal, because EA's recent games mostly use DirectX 11 or 12. Once a game is installed, Portnaut recommends a renderer for it, and in easy mode it switches the bottle to that renderer when you press Play. Compare the renderers.

Which EA games can't run

  • Games with EA's kernel-level anti-cheat, such as EA Sports FC and Battlefield, do not run under Wine, in Portnaut or elsewhere.
  • Portnaut is in public beta, and the EA app is the launcher it has been tested with least: which games work depends on the game. If one doesn't, please tell us.

If something goes wrong

  • A game isn't in the library: choose Programs › Find Programs, or Programs › Add Game… and pick its .exe.
  • A game crashes at start: search it in Will It Run? (⌘K) to see the renderer it was tested on. In easy mode Portnaut picks the renderer each time you press Play; to try another one yourself, turn easy mode off in the bottle's settings and change the renderer in its Graphics section. You can also turn on Advertise AVX instructions in the bottle's Performance & input lag section.
  • More fixes: troubleshooting covers black screens, missing DLLs, controllers and slow games.
  • Still stuck: choose Diagnostics › Export diagnostics… and email the file to builtbyargo@proton.me with what you were doing.

Questions

Can I play EA games on a Mac?

Games with a Mac version, through EA's own Mac app. Windows-only EA games can run through the Windows EA app under Wine if the game has no kernel-level anti-cheat. Portnaut sets the EA app up, but it's the launcher it has tested least.

Does the EA app work on Apple silicon?

EA's Mac app runs on Macs with Apple silicon. The Windows EA app has been run on Apple silicon through Wine 11 with Highball; Portnaut's own EA app setup hasn't been tested past EA's installer yet.

Do I need Windows or a second EA account?

No. Wine needs no copy of Windows, and you sign in with the EA account you already have. Your password goes to EA; Portnaut never sees it.
