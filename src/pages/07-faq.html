The basics

Is Portnaut free?

Yes. Portnaut is free and open-source software under the MIT licence, made by Built by Argo. You can support its development on Ko-fi if you like; donations are optional and unlock nothing, so every feature is for everyone.

What does Portnaut do?

Portnaut runs Windows games and game launchers on a Mac. It uses Wine, which provides the parts of Windows that programs rely on, and a renderer that translates the games' DirectX graphics to Apple's Metal. Portnaut sets all of this up for you, recommends settings per game, and keeps your games in a library.

Is Portnaut a Windows emulator?

No, though it does the job people look for in one. An emulator imitates a whole PC, which is slow. Portnaut uses Wine, which provides the parts of Windows that programs call directly on macOS, so no copy of Windows runs at all. On Apple silicon, Apple's Rosetta translates a game's Intel code, and a renderer translates its DirectX graphics to Metal. For games this is usually faster than running Windows in an emulator or a virtual machine. All the options compared.

Can Portnaut open .exe files?

Yes. Choose Install from File… or drop an .exe or .msi file on Portnaut's window. Portnaut runs it in a bottle and lists the programs it installed, which you can then add to your library. Most Windows installers and games work this way; programs that need Windows drivers, such as kernel-level anti-cheat, do not. Step by step: how to open .exe files on a Mac.

Do I need a copy of Windows?

No. Wine is not Windows and needs no Windows licence. You only need the games themselves, from Steam, EA, Ubisoft or elsewhere.

Can I play PC games on my MacBook?

Many, yes. Any MacBook Air or MacBook Pro with Apple silicon (M1 or later) runs Portnaut, and Windows PC games run if the game itself works under Wine. Games with kernel-level anti-cheat don't, and some games run only their single-player part. Check a game with Will It Run? before you buy or download it. A MacBook Air has no fan, so a demanding game can slow down after a while. How to play PC games on a Mac.

Which Macs does Portnaut run on?

Macs with Apple silicon (M1 or later) running macOS 14.6 or later. Intel Macs are not supported. Portnaut also needs Rosetta, which it tells you how to install if it is missing.

What is easy mode?

In easy mode, which new bottles start in, Portnaut sets each game up for you: when you press Play it switches the bottle to the renderer that suits the game (the one measured fastest on your Mac, else the one it was tested on, else the one its files suggest) and backs up your saves first. You can turn it off in the bottle's settings.

What is a bottle?

A bottle is a separate Windows environment with its own programs, settings and renderer. Portnaut keeps each launcher in its own bottle, so launchers don't affect each other.

Games

Which games work?

Many Windows games using DirectX 9, 10, 11 or 12 can run, but every game is different. Portnaut has been tested most with Assassin's Creed III Remastered through Ubisoft Connect, which plays through missions at about 60 fps on an M4 Pro. The story modes of GTA V and Red Dead Redemption 2 have been played on Macs with the same Wine. Games with kernel-level anti-cheat do not run. Check a game with Will It Run? in Portnaut first.

How do I know if a game will run?

Search it in Will It Run? (in the Library, or Command-K). Portnaut checks about 13,000 games from Highball's open compatibility database: games tested on a Mac, games Mac players report working, predictions from Linux players' results, and games blocked by kernel anti-cheat. The check happens on your Mac. Portnaut also warns you when Steam starts downloading a game that can't run.

Which launchers does Portnaut support?

Steam, the EA app, Ubisoft Connect, the Epic Games Launcher, Battle.net, the Rockstar Games Launcher, GOG Galaxy and Amazon Games are set up in a few clicks. Any other Windows installer (.exe or .msi) can be run in a bottle with Install from File.

Do online games with anti-cheat work?

Games with kernel-level anti-cheat, such as EA Sports FC and Battlefield, do not run under Wine, in Portnaut or elsewhere. Some games run, but only offline: GTA V's story mode has been played on a Mac, while GTA Online needs BattlEye's kernel anti-cheat and doesn't work. Will It Run? names a game's anti-cheat. Some online games also don't allow Wine in their terms, so check a game's rules before playing it online.

Which renderer should I choose?

Usually the one Portnaut recommends: it reads each game's files and suggests DXMT for most 64-bit DirectX 11 games, D3DMetal for DirectX 12, DXVK for 32-bit DirectX 10 and 11 games, and Wine's own renderer for older games. In easy mode Portnaut switches to each game's renderer when you press Play, so you don't have to choose. How the renderers compare.

Can I use a game controller?

Yes. Portnaut recognises Xbox, PlayStation, Switch and most other controllers through SDL and shows them to games as an Xbox controller, which most games expect.

How fast are games?

That depends on the game, the renderer and your Mac. Portnaut records the average and low frame rate of every session you start from its library, so you can compare renderers. MetalFX upscaling can help in demanding games.

Installing, safety and privacy

Why does macOS stop Portnaut the first time I open it?

Portnaut is not notarized by Apple yet. Open System Settings, then Privacy and Security, and choose Open Anyway next to the message about Portnaut. After that it opens normally.

Is Portnaut safe?

Portnaut contains only its own code and downloads Wine and the renderers from their makers' public releases on GitHub, checking each download against a published SHA-256 checksum. Launchers come from their publishers and Windows components from Microsoft. Bottles keep Windows programs apart from each other and away from your Mac's own folders, but they are not a security sandbox: only run Windows programs you trust.

Does Portnaut collect any data?

No. Portnaut has no account, no analytics and no tracking. It connects to the internet only to download what you ask for and, when you open Component Updates, to ask GitHub what is new and fetch the newest compatibility list. Will It Run? works on your Mac. See the privacy page for details.

Where are my games and saves stored?

Inside your bottles, in the Portnaut folder in your Library: ~/Library/Application Support/Portnaut. Save backups you make go to Portnaut Backups in your Documents folder.

How do I uninstall Portnaut?

Move Portnaut from Applications to the Trash. To remove your bottles and games too, also move ~/Library/Application Support/Portnaut to the Trash.

Help and support

How do I get help?

Email builtbyargo@proton.me, or in Portnaut choose Help, then Email Built by Argo Support. For a problem, attach a report from Diagnostics, Export diagnostics, and say what you were doing.

How can I support Portnaut?

By telling others about it, reporting problems, and if you like, a donation on Ko-fi. Donations are optional and unlock nothing.
