Boot Camp on an M1, M2, M3, M4 or M5 Mac?

No: Boot Camp (often written Bootcamp) only exists on Intel Macs, and a Mac with Apple silicon can't start Windows directly. What to use instead depends on what you need Windows for.

Updated 10 November 2026 · Portnaut {{version}}

Why there's no Boot Camp on Apple silicon

Boot Camp installed the ordinary Windows for Intel PCs next to macOS, so an Intel Mac could start up as a Windows PC. Macs with Apple silicon use a different kind of processor, which that Windows can't run on, and Apple doesn't offer a way to start them in Windows. Apple's Boot Camp Assistant only supports Intel Macs.

For games: Portnaut

Portnaut runs Windows games directly on macOS through Wine: Wine provides the parts of Windows that games use, Rosetta translates their Intel code, and a renderer translates their DirectX graphics to Apple's Metal. No copy of Windows runs, so there's nothing to buy and nothing to restart into.

  • What works: many games from Steam, Epic Games, the EA app, Ubisoft Connect, Battle.net, GOG and the Rockstar Games Launcher, DirectX 9 to 12. How to play PC games on a Mac.
  • What doesn't: games with kernel-level anti-cheat, and the online part of some games that otherwise run, such as GTA Online (GTA 5's story mode does run).
  • Check first: Portnaut's Will It Run? (⌘K) checks about 13,000 games before you download one.

For Windows apps: a virtual machine

A virtual machine runs a whole copy of Windows 11 for Arm in a window on your Mac. Microsoft's own support page, Options for using Windows 11 with Mac computers, names Parallels Desktop as an authorized way to do this on Macs with M1, M2 and M3 chips, and Windows 365, a Windows PC in Microsoft's cloud, as another. VMware Fusion and UTM can run Windows 11 for Arm too.

  • Good for: Windows software that needs a full copy of Windows. Windows for Arm runs most Intel programs through its own translation.
  • Less good for games: you need a Windows licence and plenty of memory and disk space, 3D graphics support is limited, and demanding games often struggle.
  • Not for drivers: Windows for Arm can't load drivers made for Intel PCs, and many anti-cheat systems refuse to run in a virtual machine.

For online games with anti-cheat: cloud gaming

Services such as GeForce NOW and Xbox Cloud Gaming run games on their own PCs and stream the picture to your Mac. They're the realistic way to play online games whose anti-cheat won't run on a Mac, as long as the service offers the game. They need a fast, steady connection and usually a subscription.

Have an Intel Mac?

Then Boot Camp is still on your Mac, in Applications › Utilities. Portnaut itself needs Apple silicon (M1 or later), so on an Intel Mac it isn't an option.

Questions

Does Boot Camp work on M1, M2, M3, M4 or M5 Macs?

No. Boot Camp only works on Intel Macs. Macs with Apple silicon can't start up in Windows, so use Portnaut for games or a virtual machine for Windows apps.

Is there Bootcamp for the MacBook Neo, Air or Pro?

Not for any model with Apple silicon, which is every MacBook sold since 2020 and the MacBook Neo. Bootcamp only works on older MacBooks with Intel processors.

Can I dual-boot Windows on a Mac with Apple silicon?

No. Apple doesn't offer a way to start these Macs in Windows. Windows 11 for Arm runs in a virtual machine instead, inside macOS.

How do I play Windows games without Boot Camp?

With Portnaut, which runs Windows games through Wine on macOS itself. It's free and needs no Windows licence. Games with kernel-level anti-cheat don't run; for those, cloud gaming is the option.

Is a virtual machine better than Wine for games?

Usually not. A virtual machine runs a whole extra operating system and has limited 3D graphics, so games tend to run better through Wine, which translates their graphics straight to Metal. A virtual machine is better for Windows apps that Wine can't handle.
