How to run the EA app on a Mac

Harbor installs the Windows EA app on an Apple silicon Mac in its own bottle, so you can play EA games that run under Wine, for free.

Tested with Harbor {{version}} on macOS 27.2 · Updated 29 October 2026

Before you start

Download and install Harbor, open it, and choose Prepare Harbor.

Install the EA app in Harbor

  1. Create an EA app bottle. Choose Bottles › New Bottle…, select EA app, keep the recommended renderer, D3DMetal, and choose Create.
  2. Install the EA app. Choose Install EA app. Harbor downloads EA's own installer; accepting EA's terms in it is your step. When it finishes, it doesn't open the EA app by itself.
  3. Sign in. Choose Open EA app and sign in. Your password goes to EA; Harbor never sees or stores it.
  4. Install a game in the EA app. Games the EA app records join Harbor's library by themselves; for anything else, choose Programs › Find Programs in the bottle.
  5. Play from Harbor's library or from the EA app.

Which renderer to use

An EA app bottle starts on D3DMetal, because EA's recent games mostly use DirectX 11 or 12. Once a game is installed, Harbor recommends a renderer for it; follow that, and give a game its own bottle if it needs a different one. Compare the renderers.

Which EA games can't run

  • Games with EA's kernel-level anti-cheat, such as EA Sports FC and Battlefield, do not run under Wine, in Harbor or elsewhere.
  • Harbor is early access, and the EA app is the launcher it has been tested with least: which games work depends on the game. If one doesn't, please tell us.

If something goes wrong

  • A game isn't in the library: choose Programs › Find Programs, or Programs › Add Game… and pick its .exe.
  • A game crashes at start: try the other recommended renderer in a second bottle, or turn on Advertise AVX instructions in the bottle's Performance section.
  • Still stuck: choose Diagnostics › Export diagnostics… and email the file to {{support_email}} with what you were doing.
