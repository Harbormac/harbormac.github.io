How to open .exe files on a Mac

An .exe file is a Windows program, so double-clicking it on a Mac does nothing useful. With Portnaut you can run Windows installers and programs on an Apple silicon Mac for free, without installing Windows.

Tested with Portnaut {{version}} on macOS 27.2 · Updated 30 October 2026

Why your Mac can't open an .exe

An .exe (and its installer cousin, the .msi) is built for Windows: it expects Windows' system files and, usually, an Intel processor. macOS has neither, so it can't start one. To run it you need something that provides the parts of Windows the program calls.

Portnaut does that with Wine, which provides those parts directly on macOS, so no copy of Windows runs and you need no Windows licence. On Apple silicon, Apple's Rosetta translates the program's Intel code, and for games a renderer translates DirectX graphics to Metal.

Before you start

Download and install Portnaut, open it, and choose Prepare Portnaut. That needs a Mac with Apple silicon (M1 or later), macOS 14.6 or later, and Rosetta. Install from File stays greyed out until Portnaut is prepared.

Run an installer (.exe or .msi)

Most Windows software comes as an installer. To run one:

  1. Choose Install from File… at the top right of Portnaut's window (or press ⌘I), and pick the .exe or .msi. You can also drop the file onto Portnaut's window.
  2. Choose where it goes. In the Install a Windows Program sheet, pick an existing bottle or New Bottle. A bottle is a separate Windows environment, so the program stays apart from everything else. For a new bottle you can choose its renderer and the Windows version programs see; the defaults are fine for most software.
  3. Click Install and go through the installer as you would on a PC. While it runs, its own folder appears to Windows as drive H:, so installers that come with extra files beside them work too.
  4. Choose what goes in your library. When the installer has finished, Portnaut lists the programs it installed, each with the renderer it recommends. Tick the ones you want and click the Add … to Library button, which shows how many you ticked.
  5. Play from Portnaut's library. Programs you didn't add stay in the bottle; Programs › Find Programs lists them again later.

Run a program that doesn't need installing

Some games and tools are just a folder with an .exe inside. Those go into a bottle's Windows drive first:

  1. In Bottles, select a bottle (or create one with New Bottle…).
  2. Choose Programs › Open C: Drive in Finder and copy the program's folder into it, for example into Program Files.
  3. Choose Programs › Add Game… and pick the program's .exe. It joins your library.

Which .exe files work

  • Usually work: game installers, game launchers, and many Windows games and tools. For launchers, Portnaut also has ready-made bottles: see the guides for Steam, the EA app and Ubisoft Connect.
  • Sometimes need extra pieces: programs that ask for the Visual C++ runtimes, .NET or DirectX helper libraries. Add them from the bottle's Windows components, which Portnaut downloads from Microsoft.
  • Don't work: anything that installs Windows drivers, including games with kernel-level anti-cheat, and Windows system tools. Every program is different, so if one fails, try a new bottle with another renderer.

Other ways to run Windows programs on a Mac

  • A virtual machine runs a whole copy of Windows for Arm inside macOS. It works with almost any program, but needs a Windows licence, plenty of memory and disk space, and many games run slower or not at all.
  • Cloud gaming streams games running on someone else's PC. It works only for the games a service offers, and needs a fast connection.
  • Boot Camp installs Windows next to macOS, but only on Intel Macs. Apple silicon Macs can't use it.

For games and everyday Windows programs, Portnaut's approach is free, needs no Windows licence, and keeps each program in its own bottle.

Questions

Is it safe to open .exe files on a Mac?

Only run Windows programs you trust, just as you would on a PC. Bottles keep Windows programs apart from each other and away from your Mac's own folders, but they are not a security sandbox.

Do I need Windows to run an .exe on a Mac?

No. Portnaut runs Windows programs with Wine, which provides the parts of Windows that programs need, so no copy of Windows runs and no Windows licence is needed.

Can Portnaut open .msi files too?

Yes. Install from File accepts both .exe and .msi files, and so does dropping a file on Portnaut's window.

Does this work on Intel Macs?

No. Portnaut needs a Mac with Apple silicon (M1 or later) and macOS 14.6 or later.
