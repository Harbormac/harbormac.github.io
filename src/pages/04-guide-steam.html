How to play Steam games on an Apple silicon Mac

Steam has its own Mac app, and for games with a Mac version that's the one to use. For the Windows-only games in your library, Portnaut runs the Windows version of Steam on a Mac or MacBook with Apple silicon, for free.

Steam tested up to its sign-in page (October 2026); no Steam game played through Portnaut yet · Updated 7 November 2026

Does Steam run on Apple silicon?

Yes, and the app and its games are separate questions:

  • Steam's Mac app: Valve added a native Apple silicon version in a June 2025 beta; before that it needed Rosetta. In Activity Monitor, the Kind column shows whether your copy runs as Apple or Intel.
  • Mac games: each game is native or needs Rosetta on its own, whichever way Steam itself runs.
  • Windows games: these need Wine, which Portnaut sets up. Wine runs through Rosetta, so Portnaut needs it.

First: does the game have a Mac version?

On a game's Steam store page, look at the system icons next to the price. An Apple logo means it has a Mac version: install it with Steam's Mac app, which usually runs it better than any Windows version could. If there's only a Windows logo, the game is Windows only, and that's what Portnaut is for.

You can use both with the same Steam account: the Mac app for your Mac games, and Steam in Portnaut for the rest.

Before you start

Download and install Portnaut, open it, and choose Prepare Portnaut. That needs a Mac with Apple silicon, macOS 14.6 or later, and Rosetta.

Play Steam games that are for Windows

  1. Create a Steam bottle. Choose Bottles › New Bottle…, select Steam, keep the recommended renderer, and choose Create. A bottle is a separate Windows environment, so Steam and its games stay apart from your other launchers.
  2. Install Steam. Choose Install Steam. Portnaut downloads Valve's own installer and installs Steam without further questions.
  3. Sign in. Choose Open Steam and sign in in Steam's window. Your password goes to Valve; Portnaut never sees or stores it. On first start Steam updates itself, which takes a while.
  4. Install a game in Steam as you would on a PC. When it finishes, it appears in Portnaut's library by itself.
  5. Play from Portnaut's library, or from Steam. Portnaut starts Steam games through Steam, also while Steam is already open.

Which renderer to use

A Steam bottle starts on D3DMetal, Apple's translation for DirectX 11 and 12, because most Steam games use one of those. Once a game is installed, Portnaut reads its files and recommends a renderer for it: often DXMT for 64-bit DirectX 11 games and D3DMetal for DirectX 12. You'll see the recommendation in the bottle's Graphics section and next to the game.

In easy mode, which new bottles start in, Portnaut switches the bottle to each game's renderer when you press Play, so one Steam bottle suits all your games. With easy mode off, the renderer applies to the whole bottle, and a game that needs a different one can have a second Steam bottle. Compare the renderers.

Tips

  • Steam's own window is drawn in software. That's deliberate and keeps it from going black; your games still use the renderer.
  • Launch options: a game's Game Settings… in Portnaut take launch arguments, which Portnaut passes to the game through Steam.
  • Controllers appear to games as Xbox controllers, and Steam Input works on top.
  • A game that needs AVX and won't start: turn on Advertise AVX instructions in the bottle's Performance & input lag section.
  • Compare renderers: Portnaut records the frame rate of every session you start from its library, so you can try a game on two renderers and see which is faster.

What doesn't work

  • Games with kernel-level anti-cheat do not run under Wine, in Portnaut or elsewhere. Some online games also forbid Wine in their terms.
  • Portnaut is in public beta. Steam installs and runs in Portnaut; how well a particular game runs depends on the game.

If something goes wrong

  • An installed game isn't in the library: in the bottle, choose Programs › Find Programs.
  • A game crashes or shows a black screen: search it in Will It Run? (⌘K) to see the renderer it was tested on. In easy mode Portnaut picks the renderer each time you press Play; to try another one yourself, turn easy mode off in the bottle's settings and change the renderer in its Graphics section.
  • More fixes: troubleshooting covers black screens, missing DLLs, controllers and slow games.
  • Still stuck: choose Diagnostics › Export diagnostics… and email the file to {{support_email}} with what you were doing.

Questions

Does Steam run on Apple silicon?

Yes. Steam's Mac app runs on Macs with Apple silicon, and Valve added a native version in a June 2025 beta. Activity Monitor's Kind column shows whether your copy runs as Apple or Intel.

Do I need Rosetta for Steam?

Not necessarily for a native copy of Steam's Mac app, though some Mac games still need it. Portnaut does need it for Windows games, because Wine runs through Rosetta. Portnaut tells you if it's missing.

How do I play Steam games on a Mac that are for Windows?

Run the Windows version of Steam in Portnaut, sign in, and install the game there. We've tested this up to Steam's sign-in page and haven't played a game this way yet, so check the game in Will It Run? first.
