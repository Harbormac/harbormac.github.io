Portnaut 0.8.0 · 30 October 2026

A new name, a new look, and the full source code.

  • Portnaut: a new name and a new icon, the gamepad planet.
  • A new look: deep-space colours with rocket-orange buttons, rounded headings, and starry scenery for games without their own artwork.
  • The full source code is now public on GitHub, under the MIT licence. It builds with Apple's Command Line Tools; Xcode isn't needed.
  • Build scripts now build inside the repository.

Everything else works as before:

  • bottles for Steam, the EA app and Ubisoft Connect;
  • a renderer recommendation for each game;
  • per-game settings and controllers;
  • Windows components from Microsoft;
  • snapshots and save backups;
  • performance records for every session;
  • component updates for Wine and the renderers, with roll back.

How to update Portnaut

Portnaut doesn't update itself yet. To move to a new version:

  1. Download the new version and open the zip.
  2. Quit Portnaut, then move the new Portnaut to your Applications folder and choose Replace.
  3. Open it. macOS may ask you to allow it again, as the first time.

Your bottles, games and saves stay where they are, in ~/Library/Application Support/Portnaut, so nothing needs setting up again.

Wine and the renderers update separately, from inside the app: choose Check for Component Updates… in the Portnaut menu. How component updates work.

To hear about new versions, open the Portnaut repository on GitHub and choose Watch › Custom › Releases.

Good to know

  • Portnaut is in early access. Keep backups of saves you care about: Back Up Saves in a bottle copies them to ~/Documents/Portnaut Backups.
  • Games with kernel-level anti-cheat don't run under Wine.
  • DirectX 12 games need D3DMetal. About D3DMetal and the Game Porting Toolkit.
