Where to start

New to Portnaut? Install it first and choose Prepare Portnaut, then pick the guide for the launcher your games are in. Each launcher gets its own bottle: a separate Windows environment, so one launcher's settings and updates never affect another.

The Ubisoft Connect guide covers the setup Portnaut has been tested with most, including Assassin's Creed III Remastered. The Steam guide suits most Windows games you already own. The EA app guide explains which EA games can run and which can't, because some need anti-cheat that Wine does not support.

Have a Windows program that isn't a game launcher? How to open .exe files on a Mac covers installers and programs that need no installing.

Every guide says which renderer to use, and DXMT vs D3DMetal vs DXVK explains them all. Portnaut recommends one for each game, and you can switch between DXMT, D3DMetal, DXVK and Wine's own in a game's settings if a game looks wrong or runs slowly. The FAQ answers the common questions.
